# HANDOFF-E: Dashboard

## What was built
- `app/Home.py` (Overview) and `app/pages/` `1_Segments.py`, `2_Guardrails.py`, `3_Explore.py`,
  `4_Methodology.py`: the five pages from PRD-E §3.1.
- `app/data.py`: all data access. Paths resolve from `PROJECT_ROOT` (cwd fallback), DuckDB is
  opened `read_only=True`, loaders are `@st.cache_data` keyed on path + mtime, and every loader
  returns `None` when its input is missing so pages show a `st.warning` naming the make target
  (`make simulate dbt`, `make analyze`, `make design`). Never reads `config/ground_truth.yaml`.
- `app/components.py`: decision banner, SRM alert, number formatting, shared Plotly styling.
  Colors: control `#8A8F98`, treatment `#3366CC`.
- `app/export.py`: `python -m app.export --out exports/powerbi/` writes `experiment_invoices.csv`,
  `summary.csv`, `segments.csv`, `guardrails.csv` and `README.md`. A relative `--out` resolves
  from `PROJECT_ROOT`. Exit code 1 (with warnings, no traceback) if any source is missing.
- `exports/powerbi/README.md`: Power BI rebuild notes (model, DAX measures for recovery rate and
  lift, suggested visuals per page). Regenerated by every export.
- `tests/app/`: fixtures + 40 tests (AppTest for all five pages × four results variants, banner
  text for every decision value, KPI count, segment selector and filters, missing-input
  warnings, export row counts and determinism).
- `app/screenshots/*.png`: each page rendered against the fixtures (`ship_segmented` results).

## How to run
```bash
streamlit run app/Home.py                      # or: make app
python -m app.export --out exports/powerbi/    # or: make export
pytest tests/app                               # ~8s
ruff check app tests/app
```

## Fixtures
- `tests/app/fixtures/build_warehouse.py` builds a 600-row seeded `fct_experiment_invoices` and
  derives both agg tables from it with SQL. The tests build it into a temp dir per session; run
  the script directly to write `tests/app/fixtures/warehouse.duckdb` locally (not committed, since
  a DuckDB file is not byte-stable).
- `results_ship.json`, `results_ship_segmented.json`, `results_guardrail_breached.json`
  (billing tickets breached → `do_not_ship`), `results_srm_failed.json` (SRM failed →
  `do_not_ship`, "invalid experiment"), `power_analysis.json`, `experiment_design.md`.

## Open issues / notes for other workstreams
1. **`tests/app/__init__.py` was removed (F / bootstrap).** With it, pytest's default
   `prepend` import mode imports `tests/app` as a top-level package called `app`, which shadows
   the real `app/` package, so `from app import export` fails. The test dir now has no
   `__init__.py`; `tests/app/app_test_paths.py` puts the repo root on `sys.path` so `import app`
   works under plain `pytest` (the editable install only covers `src/`). Alternatives for F:
   add `tests/__init__.py`, or set `addopts = "--import-mode=importlib"` in pyproject.
2. **`app` is not an installed package.** `python -m app.export` and `streamlit run app/Home.py`
   work from the repo root (pages add the root to `sys.path` themselves). If F wants
   `python -m app.export` to work from anywhere, add `app` to `[tool.setuptools.packages.find]`.
3. **`.gitignore` ignores `HANDOFF-*.md`** (same as HANDOFF-A); this file was force-added.
4. The design-doc link on Methodology points at
   `github.com/penguinme12345/payment-retry-experiment/blob/main/docs/experiment_design.md`; the
   page also renders the local file inline when it exists.
5. Tested with streamlit 1.67, plotly 6/7-compatible API, duckdb 2.0. Nothing extra needed in
   pyproject (streamlit, plotly, duckdb, pandas are already main deps). Screenshots need Node +
   Playwright, which are not project dependencies.
